# 場景載入動畫

所有正式場景切換共用 `GameSceneFlow.Load`，不需修改場景或手動掛載元件。登入成功進入主選單、角色選擇後出發、Esc 返回主選單、通關返回及未登入重新導向，都會顯示同一套畫面。

畫面使用原有地城像素封面、金框、旋轉符文及呼吸式中央菱形；同時顯示進度條、百分比、載入階段和操作提示。符文使用 UI 幾何繪製，不需外部圖片、動畫素材或額外套件。

- 先以 0.15 秒淡入，讓畫面完成渲染後才開始非同步讀取場景。
- 進度依 Unity `AsyncOperation.progress` 顯示資源載入階段；啟用場景後等待 Start、地圖啟動及啟用中的 `GameProgressSave.Ready`，最後顯示 100% 再淡出。
- 快速切換也至少顯示 0.7 秒，避免載入畫面閃爍。動畫、淡入淡出與顯示計時均使用不受暫停影響的時間。
- 畫面跨場景保留並重複使用；閒置時停用。相同目標的重複請求共用原載入，避免多個場景同時切換。
- 登入保護可以排入重新導向；先完成當前操作，再載入登入場景，期間保留遮罩。
- 載入時暫停遊戲、解鎖滑鼠、遮擋點擊並清除鍵盤選取；背包、選角、登入及設定快捷鍵也不會穿透載入畫面。
- 完成後恢復遊戲與游標；若讀檔後仍有未選完的升級，保留升級介面的暫停狀態。
- 返回選單仍先執行原有的存檔與儲存失敗確認流程。

大型場景中的同步 Awake／Start 工作仍在 Unity 主執行緒執行；該段工作耗時時，動畫可能短暫停頓。畫面會先渲染，且在初始化完成前持續遮住遊戲。

`LoginSceneReview.Run` 在隔離 Unity 專案檢查登入、選角、動畫在暫停時推進、進度、重複請求、跨場景重用、實際存檔初始化、通關返回及登入重新導向。預覽位於 `Previews/LoadingScreen.png`。

驗證：Unity 6000.3.10f1 通過 91 項登入／選角／載入整合檢查；既有 62 項角色技能與 52 項設定檢查也通過。Runtime、UNITY_EDITOR 與 Editor 工具參考編譯通過。測試使用暫存專案、模擬登入及獨立存檔路徑，未連線實際帳號服務。
