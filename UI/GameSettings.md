# 遊戲設定

主選單的「設定」與遊戲中 **Esc → 設定** 使用同一套設定頁及儲存資料，不需重新製作場景。設定保存在本機 `PlayerPrefs`，與帳號遊戲進度分開；下次開啟遊戲或直接從編輯器進入地圖時會自動載入。

設定頁上方及 **Esc → 武器說明** 可查看角色武器、三種接技流程與預設回聲操作。使用滑鼠滾輪或方向鍵捲動；返回會回到原入口。新連招依實際命中順序觸發，背包顯示三格配裝能形成的連招。調整鍵位後請先套用。[玩法說明](../Player/TacticalAdventure.md)

| 分頁 | 可調整項目 |
| --- | --- |
| 畫面與視窗 | 視窗、無邊框全螢幕、獨佔全螢幕；解析度；垂直同步；30／60／90／120／144／165／240 FPS 或無上限 |
| 滑鼠與視野 | 滑鼠靈敏度 0.20–3.00 倍；反轉第一人稱垂直滑鼠；相機垂直視野 55–110 度 |
| 音量 | 主音量、背景音樂、音效與環境音，各 0–100%；切換到其他視窗時是否靜音 |
| 自訂鍵位 | 本機玩家的鍵盤與滑鼠配置 |

在「自訂鍵位」分頁點擊操作旁的按鍵，再按下新的鍵盤或滑鼠按鍵，最後按「套用並儲存」。支援移動、跳躍、跑步、蹲下／滑行、射擊、技能、戰術回聲、誓約選擇、切換視角、背包、暫停、武器欄和醫療包。列表可捲動查看所有操作。

同一組配置內，與同情境操作重複的按鍵會交換。Esc 在錄製時取消改鍵，平常保留為返回／暫停備用鍵。錄製期間會阻擋遊戲操作，避免誤射或施放技能。同機雙人已移除，原第二位玩家的鍵位不再保留按鍵使用權。

改鍵在按下「套用並儲存」後生效；取消會丟棄草稿，「恢復預設」重設鍵位草稿。鍵位儲存在本機 `Settings.BindingsV1`，重新開啟遊戲後自動載入；舊鍵盤滑鼠設定繼續沿用。單人與連線玩家各使用自己電腦的配置，房主不會覆寫加入者的設定。技能、戰術回聲、背包及快捷武器欄的提示會顯示設定的按鍵。

滑鼠靈敏度同時用於第一、第三人稱，預設 1 倍保留原本約 60 FPS 時的操作感。滑鼠每幀位移不再乘上 `Time.deltaTime`，避免相同滑鼠移動在不同 FPS 下產生不同轉向幅度。設定頁與其他選單開啟時不讀取鏡頭轉向。

音量、靈敏度與視野的變更會先套用到執行中的系統；按「取消並返回」或關閉頁面會還原。「恢復預設」只載入草稿，仍需按「套用並儲存」。一般設定立即儲存並返回；視窗模式或解析度變更會要求在 **15 秒內確認**，否則自動恢復。倒數使用實際時間，遊戲暫停時仍有效。確認畫面會阻擋底下控制項的滑鼠與鍵盤操作。

垂直同步開啟時，FPS 上限下拉選單停用，更新速度交由螢幕更新率控制；關閉後可再次選擇上限。FPS 上限限制可達到的最高幀數，不能保證硬體能達到所選 FPS。

**Unity 編輯器中不會調整 Game View 或編輯器視窗尺寸**；視窗模式與解析度控制遊戲執行檔的視窗。其他音量、相機與 FPS 設定仍會套用到 Play 模式。

`GameSettings` 統一讀取、驗證與套用資料，`GameSettingsMenu` 負責共用 UI、預覽與顯示確認。`FPSCameraLook`／`CameraFollowTPS` 接收共用靈敏度與視野，`GameAudio`／`GameMusic` 使用獨立音量倍率。

沿用 `Settings.MasterVolume`，並相容舊的 `Settings.Fullscreen` 與 `Settings.Resolution` 索引。新設定以實際寬、高和視窗模式儲存，避免螢幕解析度清單改變後讀錯選項。新鍵包括 Width、Height、WindowMode、MusicVolume、EffectsVolume、MouseSensitivity、FieldOfView、InvertY、VSync、FrameRate、MuteInBackground（皆使用 `Settings.` 前綴）。

`GameSettingsReview.Run` 可在隔離 Unity 專案執行整合檢查；測試使用獨立設定前綴並清除測試鍵，不覆寫玩家設定或存檔。

`GameControlsReview.Run` 是移除同機模式前的歷史測試，包含已退役的第二位玩家情境。現行移除驗證使用 `Player/Verification~/LocalCoopRemovalReview.cs.txt`，僅在獨立暫存專案執行；不可在正式專案或未儲存的工作場景執行舊測試。

自訂鍵位與組合說明驗證：30 項改鍵整合、65 項設定、55 項多人整合與 18 項雙程序房主／加入者檢查通過；兩種執行期編譯條件皆通過。組合說明入口、完整 25 種內容、捲動到底與返回流程已實測，分頁亦由 Unity 渲染並檢查。[鍵位分頁預覽](Previews/KeyBindings.png)

驗證：執行版與含 UNITY_EDITOR 的執行期程式編譯通過；52 項設定整合檢查與 60 項既有玩法回歸檢查通過。涵蓋音量實際輸出、相機視野、靈敏度與反轉、儲存／重新載入、舊設定移轉、取消與預設還原、顯示確認／逾時／鍵盤焦點、Esc 暫停共存、滑桿滑鼠命中與長下拉選單捲動。三個分頁及確認畫面已用 Unity 渲染並檢查 1280×720 排版。實際作業系統視窗切換仍需在遊戲執行檔測試，未量測硬體上的實際 FPS。
