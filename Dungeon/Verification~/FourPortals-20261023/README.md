# 營地四座冒險傳送門實測

日期：2026-10-23。Unity 6000.3.10f1，在獨立測試專案 `Builds/MapSelectionReview/Project` 實際進入 Play Mode；產品名稱 `MapSelectionReview20261023`，使用獨立遊客存檔。未操作原專案編輯中的場景或正式遊戲存檔。

旅人營地北側有四座分開的實體門，由左至右對應 Map1 風語林地、Map2 赤砂遺跡、Map3 霜雪山境、Map4 燼火荒原。門各自固定目的地，以綠、金、藍、橘紅色符文及名稱／難度／三關門牌區分。玩家自行走向門、按 F、確認後出發，營地不再使用選圖清單或按鈕。

`map-play-results.txt`：213 項 Play Mode 檢查通過。

- 由營地出生位置透過真實 WASD 輸入走到北側，再橫向抵達四座門，確認路線無阻擋。
- 對四座門分別輸入 F，實際 UI 顯示該門固定的地圖；取消皆不改存檔、物品或金幣。
- 四座門牌的名稱、難度與三關文字完整容納。實際截圖確認四門與門牌皆在視野內，不被資訊面板遮住。
- 對每張地圖使用其對應門的實際確認按鈕，驗證載入正確場景、十二關碰撞／導航／敵人等級／傳送、存檔續玩、難度倍率、三階段首領與通關。
- 在 NPC 購買武器、防具、血包與背包擴充後，改走另一座門，所有本輪準備都帶入正確地圖。離開營地後續玩仍恢復購物物品。
- 鎖住測試存檔再按進入，出發會被阻止，確認對話顯示錯誤；原目的地、存檔與金幣保留，解除鎖定後可正常出發。
- 已出發後返回營地，同一張地圖的門提供續玩；其他門明確提示新一輪，取消保留原進度，確認後載入新地圖、清除舊裝備並保留金幣／武器解鎖。
- 新一輪進入地圖後，既有的戰術開局配裝會正常發放；檢查的是舊裝備 ID 未保留、新裝備為初始等級，不要求戰術配裝發放後仍只有一把武器。
