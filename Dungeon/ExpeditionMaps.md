# 自由選圖與三關冒險

選圖位於旅人營地的四座實體冒險傳送門。開始遊戲／開始新遊戲時先選擇角色、進入營地，再走到北側想去的門前按 F，確認後進入該門固定對應的地圖。四座門由左至右為風語林地、赤砂遺跡、霜雪山境與燼火荒原，各自以綠、金、藍、橘紅色符文及名稱／難度標牌區分，所有地圖立即開放。營地不再以選圖按鈕或選圖清單改變門的目的地。

尚未出發的準備期間，可自由走向任何一座門，按「進入遊戲」會保留本輪購買的武器、防具、血包、背包擴充、金幣與武器解鎖。僅靠近、開啟對話或取消都不會改動存檔；離開營地後按「繼續遊戲」也會回到營地，保留這份準備。已出發的冒險仍直接續玩原地圖；若返回營地走向同一張地圖的門，會接續原進度；若走向另一張地圖的門，則會明確提示「開始新一輪並進入」，確認後重置裝備與關卡進度、保留金幣與武器解鎖。

每張地圖都有三個獨立地形區域與雙向傳送門。完成第 1、2 關的鑰石需求後開放下一關，第 3 關完成後召喚三階段首領；擊敗最終首領即完成該張地圖。各關仍使用原本隨區域提高的敵人等級，地圖倍率再套用到一般敵人、戰術遭遇與最終首領。首領的接觸攻擊和環形彈幕也使用地圖傷害倍率。

每個帳號維持一份當前冒險存檔。「繼續遊戲」會讀取存檔的場景名稱，恢復正確地圖、所在關卡、背包、鑰石與首領狀態；首領生命倍率不會因讀檔再次疊加。營地準備中的新地圖也會記錄於同一存檔。

合作房間左側的「合作地圖」可依序切換四張地圖；建立和加入房間時需選相同地圖。房間既有的場景相符檢查與合作獨立存檔機制繼續適用。

`ExpeditionMaps.cs` 是名稱、三關清單、難度與色盤的設定來源。新地圖的場景位於 `Assets/Scenes/Map2.unity` 至 `Map4.unity`，地形預製物件、網格、材質和導航資料保存在 `ExpeditionWorlds/Map2` 至 `Map4`，可在 Edit Mode 檢視，不在載入時隨機重建。三張新地圖使用不同配置種子與專屬地景：仙人掌和遺跡石柱、覆雪松樹和冰晶柱、玄武岩柱和熔光石紋。

自動建圖入口為 `ExpeditionMapBaker.Run`，Play Mode 驗證入口為 `ExpeditionMapReview.Run`，僅允許在產品名稱 `MapSelectionReview20261023` 的獨立批次專案執行。驗證涵蓋實際 WASD 步行抵達四座門、F 開啟固定目的地、取消與存檔寫入失敗保護、購物裝備帶入四張地圖、十二關導航與傳送、實際敵人與傷害、存檔續玩、首領與通關。正式打包版與多人端到端連線需另行驗證。
