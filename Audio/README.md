# 遊戲音效

`GameAudio` 在進入 Play 或啟動遊戲時自動建立，切換場景保留同一個管理器。
不需要在場景、玩家或首領預製物件上手動掛音效。`GameSoundBank` 產生並快取
58 種原創合成音效，沒有外部下載或第三方音效素材依賴。

## 背景音樂

另有五首原創、立體聲循環配樂，已輸出成 WAV 並放入 `Resources/Music`，
遊戲直接載入壓縮後的音樂，不在遊玩途中合成長音軌。

| 場景／型態 | 曲目 | 長度 | 風格 |
| --- | --- | --- | --- |
| 主選單 | Menu | 48 秒 | 緩慢和弦、撥弦與鐘聲旋律，80 BPM |
| 地牢探索 | Dungeon | 64 秒 | 低沉長音、稀疏鼓點，60 BPM |
| 黑鐵暴君 | Boss1 | 38.4 秒 | 弦樂節奏與戰鼓，100 BPM |
| 赤焰狂戰 | Boss2 | 32 秒 | 加快節奏並加入副旋律，120 BPM |
| 深淵魔王 | Boss3 | 約 28.24 秒 | 密集弦樂與鼓點，136 BPM |

`GameMusic` 自動附加在既有音效管理器上，只使用兩個專用音源，預設交叉
淡入淡出 1.8 秒。只有玩家進入首領所在房間時才切到首領曲；沒有房間資料時，
使用同高度且距離 32 公尺內的判定。每次轉型切換相應配樂，擊敗或離開後回到探索曲。
背景音樂沿用設定中的總音量；基礎音量為音源的 32%，暫停時降至其 35%，
死亡時降至其 18%，失去視窗焦點時暫停並保留播放位置。

可透過 `Tools > Audio > Rebuild Background Music` 重新產生相同配樂。
編曲、音色及 WAV 輸出程式在 `Editor/GameMusicBuilder.cs`，音樂不含第三方取樣。
五首歌曲皆通過波形、循環接點與原生播放測試；64 項音樂檢查涵蓋主選單、
三種首領型態、距離／樓層判定、勝利、死亡、暫停、視窗焦點與總音量靜音。

| 使用情境 | 音效 |
| --- | --- |
| 主選單與介面 | 按鈕懸停、選取、點擊、滑桿／勾選／解析度操作、開關面板、儲存、進入遊戲 |
| 玩家移動 | 依實際移動距離播放腳步，跑步／蹲行音量不同；跳躍、二段跳、落地、滑行、蹲起、切換視角 |
| 槍械 | 步槍、衝鋒槍、霰彈槍、火箭筒、手槍、狙擊槍、輕機槍各自的射擊聲；裝備與切換武器 |
| 戰鬥 | 牆面命中、敵人受傷／死亡、劍揮擊、弩箭、玩家受傷、護甲受擊／破裂／回滿、低血量心跳 |
| 範圍爆炸 | 火球與其他範圍爆炸音效；手榴彈及其專用音效已移除 |
| 道具與成長 | 武器／補血包／鑰匙／經驗拾取、補血、金幣、升級、選擇升級、啟用武器組合 |
| 背包與商店 | 開關背包、ESC 暫停／返回、購買、出售、防具裝備、金幣不足／背包已滿／無法補血 |
| 地牢 | 低音量環境風聲、首次進房、解鎖通路、傳送 |
| 地圖機關 | 踩到地刺的警示音、地刺伸出、地板裂紋與石板崩落 |
| 首領與死亡 | 首領登場、每次轉型、環形彈幕、最後階段擊敗、玩家死亡與重生 |

## 播放規則

- 保留既有 `Settings.MasterVolume` 音量設定；主選單和暫停設定的滑桿可即時預聽。
- 24 個場景音源與 8 個介面音源重複使用，不為每顆彈丸建立物件。
- 場景音效依距離衰減；腳步、槍聲及玩家狀態音效在玩家本地播放。
- 世界暫停時暫停戰鬥音效，介面、升級、死亡提示仍可播放；環境聲淡出。
- 失去視窗焦點時暫停聲音；回到遊戲後恢復。
- 切換場景清除原場景的聲音，保留跨場景的選單提示音尾。
- 短時間重複事件限流，回血／經驗拾取另外限流，多聲同播時降低混音音量。
- 場景已有啟用中的 AudioListener 就沿用，沒有才啟用跟隨鏡頭的備用接收器。
- 合成與音高變化使用獨立亂數，不影響武器掉落、暴擊等遊戲亂數。

## 維護

在實際成功執行事件的位置呼叫 `GameAudio.UI`（暫停時也播放）、
`GameAudio.Local`（玩家本地戰鬥）或 `GameAudio.At`（世界位置）。
音效長度、基本音量和合成音色集中在 `GameSoundBank`。
新增選單的 Button、Slider、Toggle 和 Dropdown 會自動附加 `GameUIAudio`。
背包建立的按鈕立即附加，其餘動態介面最多 0.25 秒內附加。

目前使用原創合成音色與配樂，未加入配音。音效波形與 Unity 播放行為已在獨立
Play 模式中通過 318 項檢查，包含實際背包、商店、手榴彈、首領事件、
音量、暫停與跨場景生命週期；主地牢長時間遊玩的實際聽感仍需人工試玩確認。
