# 多人旅人營地

建立或加入 LAN／網際網路房間後，先進入旅人營地。每台電腦操作一位營地訪客，隊伍上限四人。

1. 每人從營地選擇角色，再選一項免費的專屬技能升級。
2. 使用 WASD／方向鍵移動，全員同時進入北側同一張地圖的地面圓圈。
3. 至少兩人、全員完成選角與升級、全員位於同一圈時，房主的「確認出發 [F]」才能啟動。
4. 房主確認後，由同一房間連線一起載入目的地，帶入各自的角色與開局技能升級。

更換角色會清除該玩家的開局升級，須重新選擇；重選升級只替換選項，不會累加。有人進出圈、加入、離線或變更選擇時，會取消待處理的出發確認。加入者不能透過確認指令啟動房間。冒險開始後不接受新玩家中途加入。

單人與多人遊戲後續每五級的升級也只提供該角色技能的強度、冷卻，以及範圍或持續時間三條路線。開局選擇已在營地完成，因此不再於二級重複彈出開局選項。技能升級寫入 CharacterProgress，線上房間由房主同步，客戶端不能自行決定傷害或升級次數。背包開啟時保留移動輸入。

本次協定版本為 2，所有玩家須使用同一新版遊戲。雲端轉送仍使用既有連線方式。

實測入口：`CoopCampReview.RunHost`、`RunClient`、`RunSkills`，只能在 Builds 內的獨立測試專案執行；目前結果位於 `Builds/SoloCampInventoryReview-20261025`。
