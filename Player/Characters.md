# 角色選擇與專屬技能

登入 → 主選單 → 開始遊戲／開始新遊戲 → 選擇角色 → 地圖。

選角畫面一次顯示 10 位角色，點選卡片可查看技能與冷卻。方向鍵亦可選擇，Enter 出發，Esc 返回；返回不會重設進度。有存檔時選「繼續遊戲」會沿用該角色；要換角色，選「開始新遊戲」，確認後選角。只有按下「以此角色出發」才提交新開局。

所有技能傷害乘上角色既有的攻擊力升級倍率。武器與裝備規則見 [角色武器與四部位防具](CharacterEquipment.md)；升級與連殺狂潮保留既有規則。狂射與影刃以暫時倍率接入射擊、移動及承傷計算，不會永久改寫武器數值。角色使用共同像素骨架與動畫，有各自的服裝配色、頭飾、選角肖像及第一人稱袖子配色。

範圍傷害、火域和砲台都檢查視線，穿刺光束會被牆壁阻擋。砲台每次只攻擊一個目標，低幀率時不補發大量攻擊。技能對首領走原有傷害與階段轉換流程；變身期間無效，收割不會斬殺首領。冰結會中斷普通敵人的攻擊前搖。影刃免疫無法阻止墜落死亡。

右下角顯示 R 技能、效果時間與冷卻。暫停、背包、升級及通關介面會阻止施放；冷卻和持續效果隨遊戲時間暫停。死亡、傳送及讀檔清除持續效果與部署物，保留已付出的冷卻，避免用重生或讀檔連續施放。

`GameProgressState.character` 是 v1 存檔的選用擴充欄位，記錄穩定角色 ID 與剩餘冷卻。舊存檔預設為震擊先鋒；未知 ID 安全退回預設，無效冷卻採預設完整冷卻。角色不額外修改生命或護甲上限，因此讀檔不會重複套用加成。

`CharacterSkillsReview.Run` 是明確啟動的隔離 Unity Play Mode 測試，涵蓋所有技能效果、牆壁阻擋、首領保護、存檔、冷卻、傳送與死亡。`LoginSceneReview.Run` 涵蓋登入、選角、返回、出發及畫面文字渲染。只在暫存測試專案執行，使用模擬登入及獨立存檔。

驗證結果：Unity 6000.3.10f1 執行 62 項角色檢查、79 項登入與選角檢查，另通過既有 43 項連殺與 60 項戰術回放檢查。Runtime、UNITY_EDITOR 版本及 Editor 工具編譯通過。選角畫面已實際渲染並檢查；數值平衡仍可依實際地城遊玩的節奏調整。
