# 旅人營地與跨輪商店進度

開始畫面的「旅人營地 · 交易與選圖」可進入 `Assets/Scenes/TradingHub.unity`。新遊戲也會先選角、進入營地。北側並列四座實體冒險傳送門，左至右固定對應風語林地、赤砂遺跡、霜雪山境、燼火荒原，各有名稱、難度與三關標示。營地內使用 WASD／方向鍵移動，走近想去的門或商人後按 F，也可點畫面下方的互動按鈕。Esc 關閉對話；沒有對話時返回主選單。

營地有武器商、防具商與補給商。成功交易會立即以現有存檔的原子寫入流程儲存；金幣不足、背包已滿、武器尚未解鎖或儲存失敗時，不扣款、不發物品，也不增加購買次數。血包可堆疊；背包已滿時仍可購買擴充。

金幣與累計購買武器次數會跨輪保留。同一輪的「繼續遊戲」會恢復背包。選擇「開始新遊戲」會先選角、進入營地，再於營地選圖；這會重置上一輪的武器、防具、血包與背包容量，只保留金幣與武器解鎖進度。通關畫面選擇返回主選單會結束本輪；選擇繼續探索則仍屬同一輪。原本的死亡重生流程保留，死亡時退出程式也會結算最新金幣與解鎖進度。

新一輪在營地購買的物品會記錄成準備存檔。出發前走向任何一座門都不會清除剛買的裝備與補給，確認「進入遊戲」時才提交該門的目的地。即使先返回主選單或退出程式，按「繼續遊戲」也會回到營地接續這份準備；經傳送門進入所選地圖時，會在新地圖與新角色狀態中套用本輪準備的背包。上一輪的位置、敵人進度與角色成長不會被帶入。

初始開放清單前三款武器，以及目前角色的相符武器。其他武器每累計購買兩把再開放一款，重複購買同款也計次；防具與補給不計次。解鎖規則位於 `WeaponShopProgress.cs` 的 `InitialWeapons` 與 `PurchasesPerUnlock`。營地和遊戲內暫停商店共用規則；合作背包快照也包含購買次數。

商品、售價與交易邏輯位於 `TradingHubStock.cs`；NPC、四座傳送門、場景佈置與鏡頭位於 `TradingHubWorld.cs`／`TradingHubController.cs`。`TradingHubPortal` 記錄每座門固定的地圖。已出發後回營地，走原地圖的門會續玩；走其他門則會明確要求「開始新一輪並進入」。取消不改動原進度。目的地無法儲存時留在營地，保留原存檔與物品。

營地的動態物件使用 `Resources/TradingHubSurface.mat` 作為材質範本。這個資產明確引用 URP Unlit Shader，使建置流程保留所需 Shader 與變體；不可改回只用 `Shader.Find` 建立材質，否則編輯器可正常顯示、執行版卻可能因 Shader 被剔除而在初始化時中斷。營地完成建立相機、訪客與 UI 後才允許互動。

Play Mode 驗證入口為 `TradingHubReview.Run`，僅允許在產品名稱為 `TradingHubReview20261023` 或 `MapSelectionReview20261023` 的獨立批次測試專案執行。驗證會操作實際 Login、MainMenu、TradingHub 與 Map1 場景，使用獨立的遊客存檔目錄；原始結果與畫面存放在 `Verification~`，四座實體傳送門整合後的回歸結果位於 `../Dungeon/Verification~/FourPortals-20261023`。
